Pruva support and issue reporting

Connection issues

Connect your phone to the boat's Wi-Fi network. Pruva automatically searches accessible supported sources and validates real measurements. It connects automatically when there is one source; with multiple sources, select a name. The normal flow does not require an IP address, port or protocol. If no device is found, check that the processor and network connection are on. Allow Local Network access in the iOS prompt; if previously denied, enable Pruva's Local Network permission in Settings. Connection help explains these checks; technical settings are optional for support teams and special installations. A connection does not mean all sensors are ready. H5000 installations missing GPS or true heading may need a supported network output providing those measurements.

Storage issues

Use backup export in Logbook to protect healthy records. A corrupt individual session does not prevent other records from opening. If the manifest is damaged, Recover archive relists healthy sessions while preserving original files. Files using an unknown newer schema are not silently modified.

Issue report

Share issue report below prepares a draft with version information and reproduction steps; it does not message anyone automatically. Optionally add the gateway model and firmware. Share raw field recordings only by your own choice; they may contain location and network details.

Hardware shortcuts

Use Shortcuts to assign a Pruva start/pin action to the iPhone Action Button. Volume button mode controls start pins or timer ±1 second. iOS does not expose a separate physical button event; Pruva observes volume changes. At the volume limit, an event may not occur, and Control Center changes may also trigger it. Watch actions need a current iPhone connection; undelivered actions are not shown as successful.

Get in touch

Email your question, app version and steps to reproduce. Include locations, race tracks or raw instrument data only if you choose to share them.
